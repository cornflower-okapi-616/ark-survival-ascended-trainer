# ARK Survival Ascended Trainer — feature reference

ARK Survival Ascended Trainer uses a concise workspace for character settings, resource groups, and world profiles. The feature map follows the same order as the project navigation.

| Section | Description |
|---|---|
| Character settings | Character-related parameters and the settings associated with the selected category. |
| Resource groups | Inventory and resource categories organized alongside their related values and notes. |
| World profiles | Related settings collected into named groups for a clearer configuration workflow. |

The project page follows the same section structure.
